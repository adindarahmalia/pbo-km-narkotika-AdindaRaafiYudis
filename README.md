# Knowledge Management System (KMS) Putusan Pengadilan Narkotika

## Deskripsi Proyek

Knowledge Management System (KMS) Putusan Pengadilan Narkotika merupakan aplikasi berbasis Java yang dikembangkan sebagai implementasi Tugas Besar Mata Kuliah **Pemrograman Berorientasi Objek (PBO)**.

Aplikasi ini menerapkan arsitektur **Model-View-Controller (MVC)** untuk mengelola data putusan pengadilan tindak pidana narkotika secara terstruktur. Sistem menyediakan berbagai fitur seperti penambahan data putusan, pencarian, filter, statistik, penghapusan data, serta validasi input guna membantu pengelolaan informasi putusan pengadilan secara lebih efektif.

Dalam pengembangannya, aplikasi menerapkan konsep-konsep **Object-Oriented Programming (OOP)** seperti Encapsulation, Inheritance, Polymorphism, Interface, Constructor, Method Overloading, Static Member, Exception Handling, serta penggunaan **ArrayList** sebagai struktur penyimpanan data utama. Proyek juga dikembangkan secara kolaboratif menggunakan **Git** dan **GitHub** dengan strategi branching sesuai ketentuan tugas besar.

# Cara Kompilasi

### Persyaratan

- Java Development Kit (JDK) 11 atau versi lebih baru
- IntelliJ IDEA (disarankan) atau IDE Java lainnya
- Git (opsional, apabila melakukan clone repository)

### Langkah Kompilasi

1. Clone repository

```bash
git clone https://github.com/adindarahmalia/pbo-km-narkotika-AdindaRaafiYudis
```

2. Masuk ke folder project

```bash
cd pbo-km-narkotika-AdindaRaafiYudis
```

3. Buka project menggunakan IntelliJ IDEA.

4. Pastikan Project SDK menggunakan **Java JDK 11+**.

5. Build project hingga proses kompilasi berhasil tanpa error.
